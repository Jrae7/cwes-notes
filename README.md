# cwes-notes

My personal study guide for the **CWES** certification. Organized, concise notes I use to track progress and review core concepts — kept professional and safe to share (concepts and defenses, not weaponized payloads).

> 📌 I study offensive techniques only in an **authorized lab** I own. These notes focus on *how things work and how to defend them*, which is what the material is for and what makes them safe to keep public.

## How this is organized
Each file under [`notes/`](notes/) is one topic. I fill them in as I work through the exam objectives and tag each with a confidence level so I know what to revisit.

| Topic | File | Confidence |
|-------|------|-----------|
| Study plan & objectives | [`notes/00-study-plan.md`](notes/00-study-plan.md) | — |
| Web security fundamentals | [`notes/01-web-fundamentals.md`](notes/01-web-fundamentals.md) | 🟡 |
| Authentication & session management | [`notes/02-authentication.md`](notes/02-authentication.md) | 🟡 |

| Input validation & injection | [`notes/04-input-validation.md`](notes/04-input-validation.md) | 🔴 |

Confidence key: 🟢 solid · 🟡 review · 🔴 not yet covered

Consistent, well-organized notes are the clearest signal of discipline and genuine understanding. They also make great interview talking points.
